# GRC-Portfolio-Project-02

# Micro-ISMS: VPN Compromise & XML Command Abuse
This repository contains a micro-portfolio demonstrating the core components of Governance, Risk, and Compliance (GRC). It simulates an organization's structural response to a VPN Compromise and XML Command Abuse scenario, aligning technical controls with the ISO 27001:2022 framework.

## Project Files
*   **File 1: MFA and Privileged Access Policy** - Establishes mandatory MFA enforcement, Maker-Checker authorization workflows, and strict 30-minute incident containment SLAs (Aligned to ISO 27001 Annex A 5.15, 5.17, 8.2, and 8.5).
*   **File 2: Risk Assessment** - An ISO 27005-aligned risk matrix quantifying inherent and residual risk for VPN compromise, XML Command Abuse, and delayed incident response.
